Prelaunch Atlas is a token launch radar that reads the sealed DefiLlama snapshot, fits its value curve on the protocols that already trade, and ranks every protocol that records no token by what a launch would be worth against today's record — with a costed seven-step farm plan for each one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
